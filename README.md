# Bitflinger TV — Support

Welcome to the official support repository for **Bitflinger TV**, a smart launcher for Android TV / Google TV, Android, iOS, and Web that surfaces personalized movie and show recommendations across all your streaming services.

---

## How to Get Help

### Search First

Before submitting a new issue, please [search existing issues](https://github.com/bitflinger-llc/tv_support/issues) to see if someone has already reported your problem or requested the same feature. If you find a matching issue, vote on it by clicking the **👍 thumbs up** on the issue description (or **👎 thumbs down** if you disagree with it). This helps us prioritize what matters most to users.

### Browse Documentation

- [Troubleshooting Guide](troubleshooting.md) — step-by-step fixes for the most common issues
- [Frequently Asked Questions](faq.md) — answers to common questions about features and usage

### Contact Support

For private or sensitive matters, reach our support team directly at [help@bitflinger.net](mailto:help@bitflinger.net).

---

## Submit a GitHub Issue

Use GitHub Issues to report bugs or request new features. You'll need a free GitHub account — [sign up here](https://github.com/signup) if you don't have one.

1. Go to the [Issues tab](https://github.com/bitflinger-llc/tv_support/issues)
2. Click the green **New issue** button
3. Give your issue a clear, descriptive title
4. Describe the problem in detail — include the steps to reproduce it and any error messages you saw
5. Click **Submit new issue**

> **Note:** This is a public forum. Do not include passwords, payment information, or other sensitive data in issues. Contact us at [help@bitflinger.net](mailto:help@bitflinger.net) for anything confidential.

### Voting on Issues

Community votes directly influence our roadmap. On any open issue, scroll to the first post and click:

- **👍** to signal you want this fixed or built
- **👎** to indicate it's not a priority for you
